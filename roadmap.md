# Roadmap

- [x] Tornar todo o conteúdo da landing page editável pelo master
- [x] Adicionar imagens e cores configuráveis sem alterar a estrutura
- [x] Criar versão móvel resumida e direta
- [x] Persistir configurações e atualizar a landing após salvar
- [x] Editor visual "clicar e editar", com desktop/celular e reordenação por arrastar
- [x] Validar painel, desktop e mobile
- [x] Usar somente a identidade definida pelo master no cabeçalho
- [x] Permitir ocultar seções, itens, links e imagens da landing page
- [x] Transformar o editor da landing em um criador visual com painel lateral contextual
- [x] Permitir adicionar, vincular, estilizar e reposicionar elementos individualmente
- [x] Validar salvamento e publicação das alterações no desktop e celular
- [x] Exibir no topo créditos utilizados/créditos disponíveis
- [x] Persistir os padrões globais e aplicá-los automaticamente a novos usuários
- [x] Permitir ocultar links do menu lateral sem excluí-los
- [x] Evitar conteúdo padrão visível enquanto a landing page carrega
- [x] Permitir excluir qualquer elemento da landing page (textos, botões, itens, imagens e seções)
- [x] Criar área de planos no editor: ativar/desativar e editar características
- [x] Exibir os planos ativos na landing page
- [x] Ativar pagamentos dos pacotes de créditos
- [x] Creditar automaticamente os créditos após o pagamento
- [x] Pacotes de pagamento único (150/500/1200 créditos) e plano gratuito diário
- [x] Página "Planos" no menu master e página de compra de créditos para os usuários
